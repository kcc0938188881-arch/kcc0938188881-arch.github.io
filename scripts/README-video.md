# 土地物件影片剪輯腳本

`make-land-video.sh` — 把一整個物件資料夾的照片，剪成一支帶行銷字幕與背景音樂的介紹影片。

## 一次就上手

```bash
# 1. 裝 ffmpeg（只需一次）
brew install ffmpeg          # macOS

# 2. 把 Drive 物件資料夾下載到電腦，把 shotlist.txt 和 captions.txt 放進去，然後：
TARGET=40 ./scripts/make-land-video.sh ~/Downloads/大內頭社段 AVI142.mp4
```

`TARGET=40` 就是「不管幾張照片，總長給我做成 40 秒」，腳本會自動反推每張該停多久。

## 影片長什麼樣

- 片頭字卡（深墨底 + 金色分隔線）→ 照片逐張上字幕 → 片尾字卡（含免責小字）
- 每張照片緩慢推近／拉遠（Ken Burns），一推一拉交錯
- 張與張之間 1 秒交叉溶接；畫面開頭淡入、結尾淡出
- 直式或非 16:9 的照片，兩側自動用同張照片的模糊版填滿，不會出現黑邊
- **行銷字幕**：底部平滑漸層暗罩上，金色關鍵字（大）+ 白色說明（小），關鍵字下方一道金線在 0.55 秒內由左掃出，做視覺聚焦
- 字幕等轉場收完才進場，淡入淡出各 0.45 秒，不會壓在溶接畫面上
- **背景音樂**：音量壓在 0.30（約 −10 dB，適中偏小），片頭 3 秒漸大、片尾 4 秒漸小；音樂比影片短會自動循環，長則自動裁切

## 兩個設定檔（放在素材資料夾裡）

### `shotlist.txt` — 播放順序

一行一個檔名（相對於素材資料夾）。`#` 開頭的行會被略過，可以用來暫時抽掉某張。沒有這個檔就依檔名排序。

### `captions.txt` — 行銷字幕

一行一句，格式 `關鍵字|說明文字`，**依 shotlist 的照片順序一張一句**。空行代表該張不上字幕。

```
7.4 公頃|完整相連，淺山難得的規模腹地
整筆釋出|36 筆地號一次到位
水保已通過|擋土與排水設施現地完成
```

換了照片順序，記得同步調整 captions 的行序——字幕是照行號對位的。

## 常用調整

```bash
TARGET=60 VOL=0.22 ./scripts/make-land-video.sh <資料夾> out.mp4
```

| 變數 | 預設 | 說明 |
|---|---|---|
| `TARGET` | 無 | 指定影片總長（秒），自動反推每張秒數 |
| `DUR` | `4.5` | 每張照片停留秒數（沒給 TARGET 時才用） |
| `XFADE` | `1.0` | 交叉溶接秒數 |
| `VOL` | `0.30` | 音樂音量倍率。再小一點用 `0.22`，大一點用 `0.40` |
| `FADE_IN` / `FADE_OUT` | `3.0` / `4.0` | 片頭漸大、片尾漸小秒數 |
| `BGM` | 自動找 | 指定音樂檔路徑 |
| `TITLE` / `SUBTITLE` | 大內案 | 片頭字卡兩行字 |
| `ENDLINE1` / `ENDLINE2` / `ENDLINE3` | 義鼎 / AVI142 / 免責 | 片尾字卡三行字 |
| `DEBUG_FILTER` | 無 | 設為 1 只印出濾鏡組態不編碼，排錯用 |

不想要字卡就設成空字串：`TITLE= ENDLINE1= ./scripts/make-land-video.sh ...`

## 張數與片長的搭配

字幕要看得完，每張至少需要 4 秒左右。換算下來：

| 片長 | 建議張數 |
|---|---|
| 40 秒 | 9 張 |
| 60 秒 | 13～14 張 |
| 90 秒 | 20 張 |

張數太多又硬壓短片長，字幕會來不及讀。

## 備註

- 字卡與字幕需要系統中文字型。macOS 用內建 PingFang、Windows 用微軟正黑；找不到字型時腳本會跳過所有文字，影片照樣輸出。
- 手機直拍的照片若在影片裡轉向不對，是 JPG 的 EXIF 旋轉資訊沒被讀到。用「預覽程式」把那張轉正存檔再跑一次即可。
- 出片速度約為片長的 3～5 倍時間，40 秒的片子在一般筆電約 2～4 分鐘。
- 對外版本請留意字幕內容：總價、單價、地主資訊不建議放進會被隨手轉發的影片。

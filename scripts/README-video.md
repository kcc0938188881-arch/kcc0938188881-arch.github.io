# 土地物件影片剪輯腳本

`make-land-video.sh` — 把一整個物件資料夾的照片，剪成一支帶背景音樂的介紹影片。

## 一次就上手

```bash
# 1. 裝 ffmpeg（只需一次）
brew install ffmpeg          # macOS

# 2. 把 Drive 物件資料夾下載到電腦，然後：
./scripts/make-land-video.sh ~/Downloads/AVI142-頭社段21-8-志誠 AVI142.mp4
```

跑完就得到 `AVI142.mp4`，1080p、H.264，可直接傳 LINE 或上傳 YouTube。

## 影片長什麼樣

- 片頭字卡（深墨底 + 金色分隔線）→ 照片逐張 → 片尾字卡
- 每張照片緩慢推近／拉遠（Ken Burns），一推一拉交錯，不會呆板
- 張與張之間 1 秒交叉溶接
- 直式或非 16:9 的照片，兩側自動用同張照片的模糊版填滿，不會出現黑邊
- 畫面開頭 1.2 秒淡入、結尾 1.5 秒淡出
- **背景音樂：音量壓在 0.30（約 −10 dB，適中偏小），片頭 3 秒漸大、片尾 4 秒漸小**
- 音樂比影片短會自動循環，比影片長會自動裁掉

## 常用調整

全部用環境變數，寫在指令前面即可：

```bash
DUR=5 VOL=0.22 ./scripts/make-land-video.sh <資料夾> out.mp4
```

| 變數 | 預設 | 說明 |
|---|---|---|
| `DUR` | `4.5` | 每張照片停留秒數 |
| `XFADE` | `1.0` | 交叉溶接秒數 |
| `VOL` | `0.30` | 音樂音量倍率。想再小一點用 `0.22`，想大一點用 `0.40` |
| `FADE_IN` | `3.0` | 片頭音量漸大秒數 |
| `FADE_OUT` | `4.0` | 片尾音量漸小秒數 |
| `BGM` | 自動找 | 指定音樂檔路徑，例如 `BGM=~/Music/藍山之歌.mp3` |
| `TITLE` / `SUBTITLE` | 大內案 | 片頭字卡兩行字 |
| `ENDLINE1` / `ENDLINE2` | 義鼎 / AVI142 | 片尾字卡兩行字 |

不想要字卡就設成空字串：`TITLE= ENDLINE1= ./scripts/make-land-video.sh ...`

## 備註

- 字卡需要系統中文字型。macOS 用內建 PingFang、Windows 用微軟正黑；找不到字型時腳本會跳過字卡，影片照樣輸出。
- 手機直拍的照片若在影片裡轉向不對，是 JPG 的 EXIF 旋轉資訊沒被讀到。用「預覽程式」或相簿把那張轉正存檔再跑一次即可。
- 出片速度大約是片長的 1～2 倍時間，16 張的片子在一般筆電約 2～3 分鐘。
